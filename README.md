# UTEC No Background

Firefox extension that removes the background from the UTEC Academic System login page.

## Scope

The extension only applies to:

`https://sistema-academico.utec.edu.pe/access`

It injects a small CSS rule that disables the `.login-page` background image.

## Privacy

The extension does not collect, store, transmit, or share user data.
